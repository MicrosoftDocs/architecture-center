The following IoT solution ideas demonstrate implementation patterns and possibilities to explore:

- [Azure Load Testing with custom plugins for Event Hubs and IoT Hub](../guide/testing/load-testing/load-testing-with-custom-plugins.md): Use Azure Load Testing with custom plugins to simulate IoT device traffic against Azure IoT Hub.
